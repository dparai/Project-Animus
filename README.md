# Project Animus

A private, single-user AI journal you run yourself. Write daily entries with mood and energy, and get weekly and monthly AI reflections that quote your own words back to you. Ask questions about your journal, or talk with a counselor-style chat that builds a slow, editable memory. It is built to run on one small server for one person.

Stack: Python 3.12, FastAPI, Jinja2 templates, HTMX, Tailwind, SQLite with full-text search. The language model is reached through an OpenAI-compatible API (NVIDIA-hosted Nemotron models by default).

## Not a therapist, not medical advice

Animus is a journaling tool, not a therapist, doctor or crisis service. The Counselor chat and the reflections are generated by a language model, can be wrong, and are not medical or mental-health advice. If you are in crisis or worried about your safety, contact local emergency services or a crisis line.

## Features

- **Daily entries** with mood and energy, full-text search, edit and delete, and a dashboard with streaks and statistics.
- **Weekly and monthly reflections**, written in the background. Each claim carries a short quote from your own entry; claims whose quote is not found verbatim in the entry are dropped.
- **Focus Areas** suggested by reflections, which you can mark active, done or failing.
- **Corrections remembered as AI memory**: if a reflection gets something wrong, you can correct it. Corrections are stored as memory notes, fed into later reflections, and never merged away.
- **Ask My Journal**: a question is answered from your best-matching entries, with quotes and dates that are verified against the entries before they are shown. If the journal does not mention it, it says so.
- **Counselor chat** with a memory built slowly: when a chat ends (or sits idle for 6 hours) a few short notes are written to the Memory page, where you can delete any of them.
- **Password login** (one owner, bcrypt) and **daily database backups** with retention.

## Privacy

- When you use the AI features, journal text is sent to the NVIDIA API (or whatever endpoint you set in `NVIDIA_BASE_URL`). Specifically:
  - Reflections: the entries of the week or month being reflected on, plus your memory notes.
  - Ask: your question and the best 8 matching entries (text, date, mood, energy).
  - Counselor: your recent chat messages, a few relevant entries, and your memory notes. When a chat ends, its text is sent once to write the memory notes.
- Everything else stays on your server: the database, backups, login and sessions. Without an API key no text leaves your server and the AI pages show a notice.
- No analytics and no third-party scripts. HTMX, the Tailwind script and the fonts are served locally from `app/static/`, and the Content-Security-Policy only allows your own origin.
- Read the NVIDIA API terms before sending anything personal. If that is not acceptable, do not set a key, or point `NVIDIA_BASE_URL` at a provider you trust.

## Requirements

- Python 3.12
- An NVIDIA API key for the AI features (get one at [build.nvidia.com](https://build.nvidia.com)); the journal itself works without one.
- For production: a Linux host with systemd and a reverse proxy such as Caddy for HTTPS (see `deploy/README.md`).

## Quick start (local)

    python -m venv .venv
    .venv/bin/pip install -r requirements.txt        # Windows: .venv\Scripts\pip
    cp .env.example .env && chmod 600 .env
    # edit .env and set NVIDIA_API_KEY=...
    .venv/bin/python -c "from scripts import set_password as s; raise SystemExit(s.main('.env'))"
    set -a; . ./.env; set +a                         # the app reads real environment variables, not .env itself
    .venv/bin/uvicorn --factory app.main:create_app --host 127.0.0.1 --port 8100

The password command asks twice (12 characters minimum, nothing is echoed) and writes `ANIMUS_PASSWORD_HASH` and `ANIMUS_SESSION_SECRET` into `.env`. On a server installed at `/opt/animus`, plain `python -m scripts.set_password` does the same for `/opt/animus/.env`. Without a password hash and a secret, every page returns 503.

Open http://127.0.0.1:8100. On a remote machine, keep the app on 127.0.0.1 and use an SSH tunnel:

    ssh -L 8100:127.0.0.1:8100 <SSH_USER>@<VM_IP>

then browse http://localhost:8100.

## Production

`deploy/README.md` covers the hardened systemd unit, the daily backup timer, copying backups off the server, and an HTTPS Caddy block with placeholders. To serve a public name, set `ANIMUS_ALLOWED_HOSTS=<YOUR_DOMAIN>` (it feeds both the Host check and the cross-site Origin check). Do not expose the app over plain HTTP.

## Configuration

Environment variables (put them in `.env`; see `.env.example`):

| Variable | Default | Purpose |
| --- | --- | --- |
| `ANIMUS_PASSWORD_HASH` | none | bcrypt hash of the login password, written by `scripts.set_password`. Required. |
| `ANIMUS_SESSION_SECRET` | none | signs session cookies (at least 32 characters), written by `scripts.set_password`. Required. |
| `ANIMUS_DB_PATH` | `data/vault.db` next to the code | SQLite database file |
| `ANIMUS_BACKUP_DIR` | `backups/` next to the code | where `scripts.backup` writes copies |
| `ANIMUS_ALLOWED_HOSTS` | empty | extra comma-separated host names to answer to (no scheme, port or wildcard); `localhost` and `127.0.0.1` are always allowed |
| `ANIMUS_SCHEDULER` | `on` | `off` or `0` disables the background reflection and memory scheduler |
| `NVIDIA_API_KEY` | none | API key; without it the AI pages show a notice |
| `NVIDIA_BASE_URL` | `https://integrate.api.nvidia.com/v1` | OpenAI-compatible endpoint |
| `NVIDIA_MODEL` | `nvidia/nemotron-3-ultra-550b-a55b,nvidia/nemotron-3.5-lightning-30b-a3b` | comma-separated priority list for background reflections |
| `NVIDIA_MODEL_INTERACTIVE` | same list as above | priority list for Ask, Counselor and chat memory |
| `NVIDIA_MODEL_ESCALATE` | `nvidia/nemotron-3-ultra-550b-a55b` | model Ask retries with when the first attempt finds nothing |

## Backups and import

`python -m scripts.backup` makes a consistent copy of the database (SQLite backup API) and keeps the newest copy of each of the last 14 days and 8 weeks. The systemd timer in `deploy/` runs it daily. `scripts/pull-backup.ps1` is a PowerShell helper that fetches the newest backup to your PC.

`python -m scripts.import_dayora PATH` imports entries from a Dayora JSON export. It is optional and specific to that app's export format; ignore it otherwise.

## Tests

    .venv/bin/pip install -r requirements.txt
    .venv/bin/pytest -q

The tests use temporary databases and a fake language-model client; no network or API key is needed.
